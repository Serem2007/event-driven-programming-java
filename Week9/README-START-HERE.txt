WEEK 9 - QUICK START

1. Extract the zip.
2. Open the extracted Week9_Complete folder in VS Code (the folder with pom.xml).
3. Ensure JDK 21 and Maven are installed.
4. Open Terminal > New Terminal.
5. Run each command separately:

mvn javafx:run -Djavafx.mainClass=com.example.FreezeDemo
mvn javafx:run -Djavafx.mainClass=com.example.TaskDemo
mvn javafx:run -Djavafx.mainClass=com.example.ProgressDemo
mvn javafx:run -Djavafx.mainClass=com.example.ServiceDemo

The PDFs from the course are in the reference folder. Answers and GitHub instructions are in README.md.
