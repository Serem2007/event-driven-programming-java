# Week 1 Summary: Event-Driven Programming in Java

## 1. Introduction

Event-Driven Programming (EDP) is a programming approach in which the flow of a program is controlled by events. Events can be generated by users, devices or the operating system. Examples include clicking a button, pressing a key or receiving a notification.

## 2. Important EDP Components

- **Event:** An action or occurrence detected by a program.
- **Event Source:** The component that generates an event, such as a button or keyboard.
- **Event Listener:** A component that detects and listens for events.
- **Event Handler:** The code that executes in response to an event.

## 3. Programming Paradigms

**Procedural Programming:** Executes instructions in a predefined sequence. The program controls the flow of execution.

**Event-Driven Programming:** Responds to events generated by users or the system. The user or external events influence the flow of execution.

| Procedural Programming | Event-Driven Programming |
|---|---|
| Follows a fixed sequence | Responds to events |
| Program controls execution | Events control execution |
| Less interactive | Highly interactive |
| Suitable for calculations and sequential tasks | Suitable for GUIs and interactive applications |

## 4. Event Loops and Event Queues

An **event queue** stores events waiting to be processed. An **event loop** continuously checks the queue and dispatches events for processing.

The Event Dispatch Thread (EDT) in Java Swing handles GUI events and updates Swing components.

### Event Loop Diagram

```text
Event Generated
      |
      v
Event Queue
      |
      v
Event Loop
      |
      v
Event Dispatch Thread
      |
      v
Event Handler
      |
      v
Application Updated
```

The event loop should not be blocked by long-running operations because this can make an application freeze. Background threads should handle lengthy tasks, while GUI updates should be performed safely on the EDT.

## 5. Java Swing Event Handling Example

The following code demonstrates how a button click can be handled in Java Swing:

```java
JButton button = new JButton("Click Me");

button.addActionListener(e -> {
    System.out.println("Button was clicked!");
});
```

The button is the event source, the ActionListener detects the click, and the code inside the handler executes when the event occurs.
