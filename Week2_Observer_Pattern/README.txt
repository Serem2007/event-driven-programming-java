WEEK 2 - OBSERVER PATTERN

Open this folder in VS Code. Each activity folder is independent. Open a terminal in the relevant folder and run the commands below:

Activity 1: javac *.java   then   java WeatherStationMain
Activity 2: javac *.java   then   java LegacyMain
Activity 3: javac *.java   then   java RefactoredMain
To run the original tightly coupled example in Activity 3: java TightlyCoupledSystem
Activity 4: javac *.java   then   java PropertyChangeDemo

Activity 5 answers are in SelfAssessment.md. Explanatory comparison notes are included in Activities 2 and 3.

Note: Activity 2 intentionally uses deprecated Java API classes because the exercise asks you to demonstrate them. The compiler may show a deprecation warning.
